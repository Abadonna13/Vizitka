# Vizitka

Одностраничный персональный визит-карточка на чистом HTML/CSS/JS.

Файлы:
- `vizitka.html` — основной однофайловый проект (UI, экспорт PNG/PDF, vCard).
- `4e8aff37-ce5a-4814-bdb3-5098652ea25e.jpg` — локальная фотография/аватар.

Запуск локально (быстрое тестирование):
```powershell
python -m http.server 8000
# затем открыть в браузере http://localhost:8000/vizitka.html
```

Экспорт:
- Кнопка "Скачать PNG" — экспорт изображения визитки.
- Кнопка "Экспорт в PDF" — откроет окно печати/сохранения PDF.
- Кнопка "Скачать vCard" — сохранит контакт в формате .vcf.

Советы по разработке:
- Обновляйте страницу в браузере после редактирования (F5).
- Если меняете локальные изображения, убедитесь, что они доступны при тестировании (запустите локальный сервер).

Лицензия: по умолчанию — без явной лицензии.
